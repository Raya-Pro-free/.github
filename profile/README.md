## 🧠 Overview

Raya Pro is a Photoshop panel by Jimmy McIntyre that bundles the actions landscape photographers repeat most: exposure blending, luminosity masks, dodge and burn, sharpening and colour grading, all as one-click buttons.

Published by Jimmy McIntyre. Category: Photoshop panel for landscape editing.

The archive in this repository contains the plug-in suite itself plus the integration files for Adobe Photoshop CC 2019 or newer.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🌄 Exposure Blending | Combines bracketed frames through masks instead of a global HDR merge. |
| 🌗 Luminosity Masks | Builds tonal selections for targeted contrast and colour work. |
| 🖌️ Dodge and Burn | Dedicated layers with a soft brush workflow for shaping light. |
| 🎨 Colour Grading Actions | Ready-made adjustment stacks for warmth, split toning and Orton effect. |
| 🔍 Sharpening Actions | Output and creative sharpening on separate layers. |
| 🧩 Panel Layout | Buttons grouped by stage of the edit: blend, tone, colour, output. |
| 📦 Installer Actions | Actions install into the Photoshop actions panel and stay editable. |
